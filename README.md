# Data Engineering Lab Practicals

This repository contains all the practical assignments, ETL pipelines, and mini-projects implemented as part of the Data Engineering curriculum. All experiments are executed using Python, Pandas, PySpark, Apache Airflow, and SQL.

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python 3.x
* **Data Processing & EDA:** Pandas, NumPy, Scikit-learn, Matplotlib
* **Big Data Processing:** PySpark
* **Database & Storage:** SQLite, Flat Files (CSV, JSON, XML)
* **Orchestration:** Apache Airflow
* **Environment:** Google Colab / Jupyter Notebooks

---

## 📁 Repository Structure

* `Practical_1.ipynb` — Data Handling: Parsing CSV, JSON, XML, Binary Files, Regular Expressions, and SQLite CRUD Operations
* `Practical_2_3.ipynb` — Data Preprocessing: Missing Value Treatment, Outlier Removal (IQR), Feature Selection, and EDA
* `Practical_4.ipynb` — Data Extraction: REST API Integration and Merging Flat CSV Files
* `Practical_5.ipynb` — Workflow Orchestration: Setting up Apache Airflow DAGs
* `Practical_6_8.ipynb` — ETL Pipelines: Multi-source extraction, Data Validation, and Incremental Loading
* `Practical_7.ipynb` — PySpark Operations: DataFrames, Grouping, Aggregations, and Joins
* `Practical_9_MiniProject.ipynb` — End-to-End Data Engineering Pipeline
